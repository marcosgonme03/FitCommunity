🎯 VISIÓN
────────────────────────────────────────
Aplicación deportiva integral donde usuarios registren entrenamientos,
compartan logros, interactúen con comunidad y reciban analytics avanzados.
Panel admin poderoso para moderación y business intelligence.

────────────────────────────────────────

📋 MÓDULOS PRINCIPALES (4 pilares)
────────────────────────────────────────

1️⃣ REGISTRO DE ENTRENAMIENTOS (Core)
   • Crear/editar entrenamientos con deporte, duración, intensidad
   • Plantillas guardadas para rutinas frecuentes
   • Calendario visual (día/semana/mes)
   • Estadísticas personales (calorías, consistencia, progreso)
   • Integraciones wearables (Apple Health, Google Fit, Strava)

2️⃣ COMUNIDAD Y SOCIAL
   • Feed de actividades (tipo Instagram/Twitter)
   • Sistema likes/comentarios en entrenamientos
   • Seguimiento de usuarios + recomendaciones personalizadas
   • Retos comunitarios con leaderboards
   • Grupos temáticos por deporte (CrossFit, Running, Yoga, etc.)
   • Mensajería privada entre usuarios
   • Sistema de badges/logros (gamificación)

3️⃣ PANEL ADMINISTRATIVO (Business)
   • Gestión de usuarios (view, ban, suspender)
   • Moderación de contenido (reportes, acciones)
   • Analytics dashboard (DAU, MAU, entrenamientos, calorías)
   • Gestión de retos, grupos, notificaciones masivas
   • Logs de auditoría completos
   • KPIs y reportes exportables (PDF, CSV)

4️⃣ INFRAESTRUCTURA TÉCNICA
   Backend:  Node.js + Express + TypeScript
   Frontend: React 18 + TypeScript + Tailwind CSS
   Mobile:   Web Responsive + PWA (MVP) → React Native (Fase 2)
   BD:       PostgreSQL + Redis (cache/real-time)
   Cloud:    Docker + AWS/GCP + CI/CD (GitHub Actions)

## Tips para que queden profesionales

- **Modo incógnito** del navegador: oculta extensiones de Chrome, marcadores y avatar de Google
- **Zoom al 100 %** (Ctrl+0)
- **Resolución consistente** entre capturas (idealmente 1920×1080)
- **Datos realistas, no de prueba**: registra unos pocos workouts antes de capturar para que las gráficas no estén vacías
- **Recortar herramienta dev** (F12 → cerrar) si se ve abierta
- Pega las capturas en este directorio con el nombre EXACTO de la tabla
